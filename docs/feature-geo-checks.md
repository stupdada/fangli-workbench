# GEO 检测

在工作台左侧打开「GEO 检测」，选客户后可以直接查看默认题目、连接豆包并开始检测。有主营关键词的客户默认生成 6 条非品牌题和 2 条品牌核验题，每题两次。缺少业务关键词时，在「调整本次检测」里补一个买家会搜索的词，即可生成题目。需要跟踪文章时，在同一处选择已采用的稿件并填入实际发布链接。

首次连接填写火山方舟 API Key，再从列表选择检测模型。默认是 Doubao Seed 2.1 Lite。连接设置会显示 Key 是否已保存，改模型时沿用已有 Key，也可以单独更换。配置保存在本工作台数据目录的 `geo-ark.json`，工作区备份不包含连接密钥。也可由启动环境提供 `FANGLI_GEO_ARK_API_KEY` 或 `ARK_API_KEY`，并以 `FANGLI_GEO_ARK_MODEL` 指定模型。实际检测需要方舟侧的模型调用权限，以及「应用组件库 → 应用组件」中的联网内容插件。搜索源为全网、头条图文和抖音百科。每轮最多 16 次 Responses API 请求，每次最多一轮工具调用和一个搜索关键词，费用按方舟实际账单计。

开始检测时固定品牌别名、题目、重复次数、入口、模型和目标稿件。请求以服务端账本逐条记录。停止只取消尚未发出的请求，进行中的请求仍保留其结果。超时等结果未知的情况中断余下任务。同一配置的历史检测可以原样复测。首次使用联网内容插件的整批检测建立新基线。同条件对比还要求响应中的模型身份一致。

非品牌题和品牌核验题分别显示计划数、完整回答数和品牌提及。文章引用使用最终回答的结构化引用及目标链接，缺失信息保留为不可判定。单条结果可展开查看完整回答和结构化引用。原始服务响应只保存在本机工作台数据库。
