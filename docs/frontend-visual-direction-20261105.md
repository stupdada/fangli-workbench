# 方立工作台前端美术与动效方向

记录日期：2026-11-05。

工作台以平面化为优先，保留白色工作区、浅灰操作区、石墨文字和克制的蓝色强调。通过清晰的排版、明暗对比及连贯的交互动效提升表现力。

本记录用于设计与实施交接。已确认方向用于工作台视觉、动效和局部排版；具体参数结合实际页面调校。

## 已确认的视觉方向

- 主色基调沿用现有系统：主文字 `#292b31`、次文字 `#626873`、分隔 `#e7e8ed`、侧栏 `#f5f6f8`、输入区 `#efefef`、交互蓝 `#315dc0`。
- 平面化优先。正文通过阅读宽度、页边距、段落结构和对齐关系形成清楚的内容区域。
- 增强明暗层次，区分正文、辅助信息、操作区域及选中状态。
- 沿用 MiSans，通过字号、字重、行距和间距建立排版节奏；正文更适合连续阅读，工具区更紧凑。
- 保持业务内容和既有操作语义，视觉与动态围绕实际创作过程展开。

## 已确认的动效方向

| 场景 | 动态表现 |
| --- | --- |
| 按钮与输入框 | 悬停、按下和焦点有短促、清晰的视觉反馈。 |
| 对话与分步切换 | 选中标记移动，内容短暂交接，保留同一任务的上下文。 |
| 首次发送消息 | 输入区从居中状态过渡到底部，消息流承接到上方。 |
| 展开或关闭稿件区 | 稿件区与对话区协调调整空间，关闭后仍可重新打开。 |
| 资料与审阅面板 | 进入与退出方向一致，保持正文和面板的空间关系。 |
| 切换稿件 | 正文区域短暂交接，工具和稿件列表保持稳定。 |
| 执行任务 | 轻量动态指示配合真实当前活动；活动变化时文字短暂过渡。 |
| 稿件完成 | 对应列表项和状态图标有一次清楚的完成反馈。 |
| 保存、复制和采用 | 操作附近显示及时的确认反馈，采用结果由实际操作响应决定。 |

动效性格为反应快、略有弹性、迅速停稳。初始调校范围：普通反馈约 120—180ms，常规切换约 150—220ms，弹性反馈约 220—300ms，较大分区展开约 250—300ms；具体参数在实施后的实际页面中调校。

- 分隔线拖动即时跟手，松手后保存宽度。
- 连续操作可中断过渡，并转向最新目标。
- 流式正文按真实返回节奏更新，已经显示的内容保持稳定。
- 用户阅读期间保留滚动位置，新内容通过局部提示呈现。
- 执行期间的持续动效随实际运行状态开始和结束；完成、失败、暂停及等待用户输入使用对应状态。
- 尊重系统减少动态效果的偏好，保留必要的操作反馈与状态信息。

## 已确认的弹性动效

整体使用轻回弹，发送按钮、选中标记和完成图标可更明显。弹性来自按下压缩、松手回弹、轻微越过目标后迅速停稳，与平面化视觉同时成立。

| 对象 | 弹性表现 |
| --- | --- |
| 按钮 | 按下缩小，松手略微放大再恢复。缩放可从 97% → 101.5% → 100% 开始调校。 |
| 切换标记 | 蓝色下划线前端先移动、尾端跟上，到新位置轻轻收住。 |
| 小弹窗、菜单和提示气泡 | 从略小尺寸展开，末端一次小幅回落。 |
| 大面板 | 起步干脆，末端轻微回落，正文排版保持稳定。 |
| 完成图标 | 小幅放大再收回，表达实际成功结果。 |

正文与输入文字保持稳定。具体时长、缩放比例和回弹幅度为实施时的调校参数。

## 已确认的空间层次

使用分栏、留白、对齐、区域底色和细分隔表达层级。菜单与设置弹窗使用细边界，正文与操作区保持清晰的平面关系。

## 已确认的品牌细节方向

统一方立字标、MiSans 字重节奏、SVG 图标笔画、分隔线和选中标记的表现，贯穿任务导航、创作入口、稿件与辅助面板。

## 已确认的蓝色分配

沿用 `#315dc0`，将蓝色集中在少量有明确交互意义的位置。

| 位置 | 分配方式 |
| --- | --- |
| 发送、开始写作等主操作 | 延续石墨黑主按钮。 |
| 当前模式或导航位置 | 顶部模式采用白色胶囊选中块；稿件导航以蓝色细下划线标记，文字保留深色。 |
| 当前选中的稿件或选项 | 可用同一蓝色以约 5%—8% 透明度叠加白色形成浅底，配深色文字及清楚的选中标记。 |
| 输入与键盘焦点 | 使用清楚的蓝色焦点线，保持可辨识度。 |
| 链接 | 真实可点击链接使用蓝色，并提供悬停和键盘焦点反馈。 |
| 任务进行中 | 小型指示符可使用蓝色，活动说明保持石墨色或灰色。 |
| 正文、普通图标与辅助信息 | 沿用石墨和灰色；完成、错误与警告沿用各自语义。 |

## 与现有创作体验方案的衔接

[优化工作台动态创作体验](codex://threads/01a1a737-edda-7581-a858-e59a24b87c22)讨论的持续对话、可关闭且可拖宽的稿件区、真实活动反馈和格式渲染，是本动效方向的主要应用场景。

视觉动效消费真实状态并保留任务、输入、选中稿件和阅读位置。任务冻结、处理中稿件只读、候选与采用、版本冲突及导出等行为继续遵循 [整合接口与产品约定](integration-contract.md)。

## 已确认的补充细节

以下细节纳入本轮视觉与动效方案。

- 滚动边界：固定工具栏在内容滚动后显出细分隔，返回顶部时恢复简洁；侧栏与正文各自明确滚动边界。
- 内容变化的稳定性：等待指示、确认文字和稿件数量变化时，给相邻控件保留稳定位置；骨架占位尽量接近最终内容结构。
- 悬停与选中区分：悬停使用浅灰响应，持续选中使用已确认的蓝色标记，键盘焦点保持清楚可见。
- 复杂内容排版：用长标题、多稿件标签、表格、引用及中英数字混排检查省略、换行、对齐和溢出表现。

## 同页导航与选中线

创作方式切换先保存当前草稿，再在当前文档更新视图、标题和任务URL。分步到对话向左滑，对话到分步向右滑；四个分步页面前进向左、返回向右，过渡约260ms。只有最新选择保存成功后才切换，保存失败保留当前视图，迟到结果不改变另一个任务。

稿件标签的选中线以真实像素宽度绘制，按文字标签定位，监听字体和容器尺寸变化。顶部创作方式现使用居中“对话 / 分步”胶囊，选中块按按钮完整宽度滑动。输入条的平台安排入口显示一个设置图标，保留可访问名称与原有安排窗口。

### 任务切换与中部创作区

空白任务切到带稿件任务时，旧实现让新内容沿用全宽，再把网格压缩到两栏，导致每帧重排。现以工作区为范围使用View Transition快照：先一次提交目标布局，再完成220ms整体过渡；旧页面约100ms淡出。跨任务期间停止局部进入和网格动画，同一任务的稿件展开、关闭与调宽继续使用既有规则。快照回调前的多次刷新合并，过渡中再切任务会取消旧过渡；过期收尾不解除新布局锁。低动态偏好及缺少快照能力时一次显示最终布局。

首次输入区参考用户提供的GPT截图随视口高度下移，标题居中；1700×982参考尺寸下，输入区中心位于视口高度约48%，顶部胶囊中心与主工作区中心误差0px。窄屏顶部使用两行排布，胶囊单独居中。既有发布安排与功能入口保留。

本轮9项focused检查通过，覆盖过渡回调合并、连续切换、异常/退出清理、低动态与能力边界，以及既有模式保存竞态。内置Browser切换采样65帧中网格列宽始终为 `410.792px 9px 616.208px`，网格过渡数量0，真实捕获快照进入/退出动画；同任务关闭稿件区仍观察到280ms网格过渡。快速往返保留未发送草稿，URL与当前任务一致；390px无横向溢出，reduce下动画数量0。未发起模型调用。

## 自然交流与流式回复

对话中的助手主消息来自模型返回的understanding，提示词要求直接回应用户，用“你”“我们”正常交流。需要澄清时自然提问，选项单独显示；程序仍负责等待提示、按钮和操作状态。实际措辞随模型返回变化。

访谈复用同一次模型调用，后端从真实片段提取可安全显示的回复，经SSE推送到同一消息节点。结构化安排在完整JSON校验并检查停止状态后生效。停止、无效输出或断线保留消息草稿和已收到的部分回复，标明未完成或待确认；显式恢复只重接现有操作。完成后移除光标和等待状态。原有选项、追问开关、开始写作与文章版本规则继续使用。

验证复用前端43项合同检查，补充断线状态图标检查；后端覆盖回复先到而安排未改、终态重接、校验失败、停止、提交后取消及现有有效输入边界。旧通用模型夹具补齐既有合同要求的完整note后，连续追问与写作暂停集成检查通过。

内置Browser连接隔离HTTP/SQLite与固定模型夹具，观察到回复从空白连续增长至完成，回复及输入节点始终保留。中途停止保留部分文字和草稿，原有效说明未应用停止消息；390px窄屏没有横向溢出。截图和采样位于 `../../output/natural-dialogue-20261105/`：`natural-dialogue-desktop.png`、`streaming-desktop.png`、`stopped-mobile.png`、`stream-samples.json`、`stop-result.json`。这些证据验证交互和状态边界；本轮真实模型调用为0，实际自然交流质量待用户使用真实模型判断。
