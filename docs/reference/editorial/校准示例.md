# 写作策略校准示例

2026-11-04。以下修改后文字均为本阶段人工编辑的策略校准示例，没有调用DS、WorkBuddy或其他模型API；不是Agent自动生成验收，也不是新认可样稿。参数复用既有订正和参考稿，本阶段未重新外部核验。示例长度仅对应局部任务，不证明完整长文达标。

## 1. 工业长回答：保留内容，把工艺写成可理解的区别

当前段落来自手写参考稿 `output/article-2026-11-03/西邦24的用途与单涂工序.txt`，不是自动成稿：

> 单涂说的是涂层体系的构成。同一种西邦24可以分多遍施涂，以达到所需的干膜厚度。因此，安排作业时仍要看实际施涂方式和膜厚要求，表面预处理、清洁与干燥也都是粘接过程的一部分。

它有用的信息是同一种胶、可分遍、膜厚、清洁与干燥。末句落回泛化提醒，后文又分别提醒材料、温度、生产条件，累积后像选型审核。调整为把这些条件连成具体施工说明：

> 西邦24使用同一种胶粘剂建立粘接层，可按所需膜厚分遍施涂。施工前先清洁并处理基材表面，施胶后让胶层充分干燥，再进入与橡胶加热成型的工序。一般用途的干膜厚度为15—20 μm；重点考虑耐环境性能时为20—35 μm。干燥条件分别为23°C下30—45分钟、60°C下约5分钟。

保留材料与膜厚目的、温度与时间配对。这里只合并相邻施工信息，完整稿仍需保留用途、胶种差异、成型与服役温度的区别。普通NBR的网页兼容清单不能代替选型表等级，品牌用途不自动赋给24。

## 2. 工序价值：具体说明收益，成本保持条件

既有真实客户稿的问题段落由 `output/review-2026-11-03/writing-review.md` 第5节逐字保存：

> 单涂最直接的好处是省掉一道底涂，但选型不能只看这一点。西邦24的单价高于竞争对手，综合成本逻辑落在胶水用量、VOC压力、降低能耗和工人效率这些工厂整体运行成本上。

用户已认可的句对把“工序”写实，但只代表这类表达，不是竞争价格或节约效果的依据。修改后可作为长文一个小节：

> 采用底涂加面涂的方案，需要准备两种胶粘剂：先施底涂，待它干燥后再施面涂。三洋物产贸易（上海）有限公司代理进口的西邦24（Cilbond 24）使用同一种胶粘剂建立粘接层，可省去独立底涂的备料、施胶和干燥。原来分两个工位施工的生产线，可少安排一道底涂工位；同一工位施工时，则可减少两种材料之间的切换。
>
> 这类工序变化是比较方案的一个起点。整套作业的成本还包括胶粘剂价格、实际用量和干燥安排，适合放在同一批零件、相同生产条件下比较。单涂体系本身支持的是工序简化，实际施涂仍可分遍完成。

工位与切换为带前提的编辑推演，不冒充某客户产线实测。不使用竞争价格、节约比例或总成本必降结论。

## 3. 社区回答：结尾服务于问题，客户关系留在内容中

同一手写参考稿末段：

> 向三洋了解西邦24的代理进口供货时，可以同时说明所用胶料、基材、表面处理方式和成型条件。把这些信息说清楚，产品型号、工艺要求与采购需求才能对应起来。

本任务是普通读者的知乎回答，已有社区规则排除采购号召。不是删除三洋，而是把关系放回介绍产品的段落，结尾回答原问题：

> 三洋物产贸易（上海）有限公司代理进口的西邦24（Cilbond 24），可用于天然橡胶、丁苯橡胶等橡胶与钢、铝等基材的粘接，采用单涂体系。它值得比较的工序价值，在于使用同一种胶粘剂完成粘接层，减少独立底涂环节。

结尾示例：

> 对正在比较两套涂胶方案的人，单涂提供了一个具体区别：所需胶粘剂种类和独立底涂工序减少。胶料、基材与成型条件决定方案能否适配，实际用量、价格与干燥安排再决定这项变化的经济价值。

这里选择已支持的具体胶种和基材进入介绍，不用编辑占位说法代替内容。完整选型稿仍需说明等级差别；短稿选择与主题相关的材料即可，不能为缩短而丢失改变结论的条件。

## 4. 宠易购：问题可组织回答，不成为店铺保证

宠易购任务实际正文为0字，因此没有宠易购“原稿问题段落”。采用 `pet-research.json` 中实际读取的721字符问题清单作校准。标题给出“宠易购精品猫舍犬舍”，同文明确面向浦东新区及周边读者；Q4问“哪家宠物店能买到健康有保障的猫狗”。这些信息支持店名、场景和读者，不支持该店有健康保证、某地址、某价格或作者到过店。

知乎回答示例，回答“了解宠易购精品猫舍犬舍时，先问清哪些选购问题？”：

> 了解宠易购精品猫舍犬舍，可以先把选购问题问具体：现在有哪些猫狗可选，自己能承担怎样的日常照料，以及购买条件怎样约定。对浦东新区及周边第一次准备养猫的人，这些问题比只看一张照片更有助于比较。
>
> 先从自己的生活安排问起。平时能留出多少照料时间，家里怎样安排猫的活动空间，日常支出准备到什么范围？带着这些考虑了解可选猫只，再逐只询问年龄、日常饲喂情况，以及有哪些记录可以查看。
>
> 购买条件也适合在作决定前逐项谈清，例如价格包括哪些项目、交付时提供什么记录、双方如何约定后续问题的处理。把实际答复放在一起比较，更容易判断是否适合自己的准备和预算。

问题表述不把记录、服务或保障写成已存在。没有写具体疾病判断或健康承诺，也没有到店故事。未知营业时间、地址和服务条款留在编辑备注；不另写一段“本稿缺资料”的正文说明。

## 5. 防御性说明：原验收素材不能成为真实客户的叙述身份

## 6. 同事实、不同形式：文章、回答、抖音图文与口播

文章可将工序价值作为议题，逐步展开工序、材料、施工条件和成本考虑；回答首段直接回答所问，例如“西邦24的单涂价值，主要在于减少独立底涂的备料、施胶和干燥”。两者都保留事实条件，组织入口不同。

### 抖音口播：连续说清一个判断

分镜：开场用两种材料的工序线图承接第一句；中段切换为单涂体系线图，并显示“可分遍施涂”；末段呈现价格、用量、干燥安排三个比较项目。时长待实际朗读确认。

配文：三洋物产贸易（上海）有限公司代理进口西邦24（Cilbond 24）。本条说明单涂体系的工序变化，施工条件应与所用胶料、基材和成型条件对应。

图文的条件放在相关页，配文清楚关联公司与产品；口播先连续讲解，分镜承接同一段话，不能把长文逐句换行当脚本。两个示例不代表同批两篇差异合格，实际多篇应按下表分工。
