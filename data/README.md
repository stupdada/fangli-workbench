# data/ —— 运行期数据目录（内容不纳入版本管理）

首次启动时程序会自动创建本目录下的 `geo.db` 并写入种子数据（平台画像、风险清单、偏好表），
**无需手工建库、无需执行 SQL**。

| 文件 / 目录 | 内容 |
|---|---|
| `geo.db` | 方案、稿件、客户资料全文、偏好表、风险清单、全局设置（含明文 API Key） |
| `geo.db-wal` / `geo.db-shm` | SQLite WAL 模式附带文件，随库一起备份 |
| `archive/plan_*/` | 点「上传服务器」后生成的归档包（`plan.json` + 每篇 `.md`） |
| `dev.db` | 「启动_开发模式.bat」使用的独立开发库 |

注意：

- **不要提交 `*.db`**：里面是真实客户资料和 API Key。`.gitignore` 已排除。
- 备份 = 直接拷走整个 `data` 目录；恢复 = 拷回同名位置。
- 想换位置：设置环境变量 `GEO_DB=D:\somewhere\geo.db`。
- 想重置：关掉程序，删除 `geo.db*` 三个文件，下次启动会自动重建。
- 库里出现 `geo.db.damaged_*` 说明程序检测到数据库损坏并自动隔离，可保留用于排查。
